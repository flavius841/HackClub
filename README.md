# Hill Car Game

---

**Hill Car Game**  is a car video game built using the **Unity Engine**.

---

🎮 **Play the game here:**  
https://flavius123.itch.io/hill-climb-car-game

---

🛠 **Run or continue development locally:**

1. Download or clone this repository.
2. Open the project using the **Unity Editor**.
3. Make sure you are using **Unity 6.2 (6000.2.6f1)**.

> **Note:** The project is only compatible with Unity version **6.2 (6000.2.6f1)**.

---

Enjoy playing or improving the game!
